Dica de Produtividade

Utilize as classes de flexbox e grid em conjunto com breakpoints responsivos (sm:, md:, lg:) para um layout fluido.

Guia de Classes Utilizadas no Projeto

Mapeamento didático de mais de 30 classes divididas por suas respectivas categorias funcionais.

1. Cores & Gradientes

  • bg-slate-950 (fundo base)
  • text-slate-100 (texto claro)
  • text-emerald-400 (destaque verde)
  • bg-gradient-to-r (gradiente linear)
  • bg-clip-text (máscara no texto)

2. Tipografia

  • text-xs / text-sm / text-3xl
  • font-extrabold / font-semibold
  • tracking-tight / tracking-wider
  • leading-relaxed / leading-tight
  • uppercase / text-center

3. Espaçamento & Dimensões

  • p-4 / p-6 / px-4 / py-3 (padding)
  • mx-auto / mt-2 / mb-4 (margin)
  • space-x-4 / space-y-6 (espaço filho)
  • w-full / max-w-7xl (larguras)
  • min-h-screen / h-16 / w-10 (alturas)

4. Bordas & Sombras

  • rounded-xl / rounded-2xl / rounded-full
  • border / border-slate-800
  • ring-1 / ring-white/20
  • shadow-lg / shadow-indigo-500/30
  • divide-y / divide-slate-800

5. Flexbox

  • flex / inline-flex
  • items-center / items-stretch
  • justify-between / justify-center
  • flex-col / flex-row
  • items-baseline

6. CSS Grid

  • grid
  • grid-cols-1
  • gap-4 / gap-6
  • lg:col-span-2
  • lg:grid-cols-3 / lg:grid-cols-4

7. Posicionamento

  • relative / absolute / sticky
  • top-0 / top-1.5 / right-1.5
  • z-50 / z-10
  • overflow-hidden / overflow-x-auto
  • pointer-events-none

8. Responsividade & Estados

  • sm:px-6 / sm:text-5xl (breakpoint sm)
  • md:flex / hidden (breakpoint md)
  • hover:scale-105 / hover:bg-indigo-500
  • transition-all / duration-300
  • group / group-hover:scale-110
